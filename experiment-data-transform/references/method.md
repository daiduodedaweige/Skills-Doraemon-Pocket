# 条件代理模型与约束采样

## 方法选择理由

本 skill 优先采用 GPR 加分层计数采样，而不是 SDV 整表条件生成：目标是解释配置变化，并检查预测误差及指标依赖；小样本、低维条件预测更契合此目标。GPR 不是无条件必胜，须与简单基线比较。数据规模、维度或可识别性不适合时，不勉强拟合 GPR。输入描述不能充当新增训练观测。

## 数据准备与验证

每行尽量对应一次实验，输入可包括设计规模、模块类型、模型、topK、迭代上限、随机种子；输出可包括断言计数、编译计数、证明计数、空洞计数、覆盖项计数和耗时。

- 明确分母：空洞占全部断言还是证明通过断言，覆盖率是语句覆盖还是 harness cover。不同定义不混用。
- 只在训练折拟合缩放器、类别编码和其他预处理，类别不能简单映射为带顺序的整数。
- 预测新设计时按设计分组留出；预测新配置时按配置分组；重复运行留在同一组，防止泄漏。
- 小数据使用分组交叉验证；若独立组少到不能有效验证，报告限制，不伪造泛化指标。
- 基线可用训练均值或正则线性回归。GPR 可用 scikit-learn 的 `GaussianProcessRegressor`，输入标准化，核从常数乘 Matérn 加 WhiteKernel 开始；区分观测噪声与数值稳定项。
- 在原始单位比较留出 MAE/RMSE；区间需验证经验覆盖率。不要只报告训练误差。仅有汇总均值时不能推导重复实验方差。

## 按依赖关系生成

先建立由统计定义保证的依赖图，再选择原始量建模。示例仅在确有集合包含关系时成立：

`0 <= 非空洞证明数 <= 证明数 <= 编译数 <= 生成数`。

可对条件概率使用平滑后的 logit 变换，再用 GPR 预测。还原后逐层从相应分母采样二项计数；生成数若固定就不重新采样，未知总数需单独明确计数模型。对于互斥且穷尽的类别，联合生成类别计数，使总和等于分母。不要把语义上独立的计数强行纳入这条链。

- 覆盖率有覆盖项计数时优先生成整数分子再求比例；没有分母时只生成有界比例，不反推虚构总数。
- 正耗时可建模对数，再正确区分还原后的均值与中位数。
- 多指标共同波动时，可联合重采样同一实验单位的留出残差向量；分别独立 GPR 不能宣称保留了相关性。残差不足时说明相关性不可估计。
- 对变换后的目标用联合预测样本经逆变换计算均值、分位数；逆变换预测均值通常不等于原尺度均值。
- 统计依赖、模型预测不确定性和实验抽样波动分开处理，避免对已经包含的噪声重复采样。只有明确的采样模型才使用二项分布，不能默认所有硬件指标都由独立伯努利试验产生。
- 原始定义若不保证“迭代更多必然更优”，不施加该单调性。用户指定单调场景时可作为合成假设，并记录。

范围外数值、未见类别、未见配置组合分别标记；单变量都在范围内也不保证组合有数据支持。缺少观测不能用模型自信度替代实验依据。

## 精确统计约定

百分比 `100 * numerator / denominator`，仅在展示时舍入。分母为零用原格式的缺失标记，不改成 0%。宏平均是逐组比例的算术均值，微平均是合并分子除以合并分母，不能相互替代。互补比例从未舍入值计算；若只有已舍入比例，只能给出相同精度的互补结果，不能声称恢复了原始精度。

可复现信息至少包含实际使用的特征、训练分组、模型参数、依赖版本、种子及生成规则；模型验证指标和区间必须由执行结果产生。环境缺少依赖时说明并按执行权限处理，不把未执行方案写成已验证结果。
