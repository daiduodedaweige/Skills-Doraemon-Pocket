# 实验数据条件变换

输入为一份实验数据和一段描述，输出为与输入同格式的数据。默认使用中文理解需求，保留原表语言。方法采用 **GPR 条件代理模型＋分层计数采样＋约束检查**；方法细节见 [references/method.md](references/method.md)。不要为了使用模型而对可精确重算的量做预测。

## 输入与判断

读取数据和描述，识别实验单位、输入配置、输出指标、分母、单位、聚合口径及用户希望修改的量。保留未要求改变的行列及单元格。对于 LaTeX 输入先阅读 [references/latex.md](references/latex.md)。

按实际证据选择以下路径：

- **确定性重算**：已有原始计数，描述明确修改计数、分母或统计范围。按定义重算所有受影响的指标；若只改变分母且描述要求保持分子不变，就保持分子。
- **条件预测**：有多个配置及对应结果，目标变量在数据中实际变化，并且目标配置有足够支撑。比较简单基线与 GPR 的留出误差，优先使用验证更好的模型；性能接近时用更简单者。
- **假设合成**：用户明确允许模拟，并给出足够的数值变化规则、范围或波动假设。依据这些假设构造场景，不能声称模型从原数据学到了该效果。
- **信息不足**：只有汇总百分比、目标变量始终不变、未见的新方法，或“提升一点”等描述无法确定幅度。指出缺少的关键条件，集中询问原始记录、分母或合成假设；不要自行编造变化效果。若已有独立可计算部分，可先完成该部分并说明剩余项。

“数据看起来合理”不等于有预测依据。各个方法名称不能当作可连续插值的数值变量；跨设计差异不能替代某个超参数的实验变化。

## 处理

1. 将文字要求转为配置变化与约束；区分用户的场景假设和数据定义。仅在未指定但不影响数值语义的实现细节上自行决定。
2. 保留源数据，默认写入同目录新文件 `<原名>_generated.<扩展名>`；用户指定输出路径时遵循指定路径。内联输入默认内联输出。
3. 重算、拟合或采样；有随机过程时使用并记录随机种子，默认 `42`。预测默认交付条件均值，明确要求样本时交付可复现样本。不要将为整数展示而四舍五入的期望计数当作实测计数。
4. 检查范围、整数性、定义成立的包含关系、互补关系、总计、比例与聚合口径。比例统一从计数计算；不明确的分母先澄清。失败时纠正生成逻辑，不通过逐格截断来掩盖不一致。
5. 依照输入精度和格式输出；按最终显示精度重新计算最优值及并列加粗，尊重每列优劣方向。除非描述要求，否则不调整排名来迎合预期结论。

## 交付

主产物保持输入的序列化格式、表结构、行列顺序、单位和展示精度。不可将解释文字或新字段塞入数据区。按需输出多个样本文件，不默认增加表格列。

生成数据须可辨别：LaTeX 用 `%` 注释、支持注释的格式用对应注释，严格 JSON/CSV 等用 `<输出文件>.meta.json`；内联且格式不支持注释时在代码块外附简短说明。元信息记录数据性质（重算／预测／假设合成）、源文件、变化规则、建模假设、随机种子（如有）、验证结果与插值／外推状态。预测区间只有实际计算过才能报告；缺少验证或无法估计时如实注明。注释和元信息不将合成结果描述为实测结果。

完成前验证输出能被原格式读取，并检查结构与原输入一致；LaTeX 检查环境、行列、转义和宏，项目已有可用构建入口时执行相应编译。最终给出文件链接、所用路径与关键限制；用户只要数据时保持回答简短。
